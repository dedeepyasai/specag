How to Participate

Asking a Question

  1. Go to GitHub Discussions → Q&A
  2. Check if your question has already been answered
  3. If not, click New Discussion
  4. Choose the Q&A category
  5. Include your tier (T1/T2/T3), what you tried, and what happened
  6. Community members and maintainers will respond

Answering Questions

Browse the Q&A section and help others. Accepted answers float to the top and help everyone searching for the same issue later.

Reporting Bugs

Found a bug? Open an issue on GitHub with:

  • What you tried to do
  • What happened (include error output)
  • What you expected
  • Your tier, Python version, and OS

Contributing Code

We welcome contributions. See the Contributing Guide for setup instructions and PR guidelines. The highest-impact contributions right now:

  • Use it — try SpecAg on a real project and report what broke
  • Write an example project — build something and submit to examples/
  • Add a hook — implement a custom PreCallHook for a use case we haven't covered
  • Improve docs — fix unclear sections, add diagrams
