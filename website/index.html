Why SpecAg?

Most AI coding tools solve the typing problem. SpecAg solves the engineering process problem.

💰

Hard Cost Enforcement

Pre-call hook chain stops API calls before they happen. Daily/weekly token caps with automatic pause. Your bill never surprises you.

📝

Spec-Driven Development

No code without a spec. No commit without a spec reference. AI agents have no memory between sessions — the spec IS their memory.

⚖

Stakes-Based Tiers

Tier by project stakes, not user count. A HIPAA app with 20 users needs more rigor than a meme app with 10M users.

⏰

Cascading Blocker SLA

When work is blocked: T+1 nudge, T+3 escalation, T+7 hard pause. Zero token spend on blocked paths until a human responds.

👥

4-Role AI Team

1 human Advisor + Lead Dev (AI) + Associate (AI) + PO Agent (AI). All coordination over Slack. No meetings. No Jira.

⚡

Pluggable Hooks

6 default hooks (DailyCap, WeeklyCap, WorkWindow, PausedRegistry, PCMode, BudgetGuard). Add your own without touching core code.
